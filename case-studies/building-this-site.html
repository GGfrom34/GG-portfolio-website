Building This Site

Problem

I wanted a portfolio that proves its own point: that a product manager can direct AI to build real, working software. So instead of using a template or a website builder, I built the site with Claude Code, Anthropic's AI coding assistant, and kept a clear record of how it came together.

Approach

I started with a simple brief: a home page, a couple of case study pages, and a clean design that loads fast. From there I worked one small change at a time, and every change was previewed in a real browser, on desktop and mobile, before it went live.

  • I set the standard for how changes ship. Every update was previewed first, then approved by me before it was published.
  • I chose between options rather than accepting a default. For the site's icon, Claude Code designed five different concepts side by side, and I picked the one I liked.
  • I kept the decisions in my hands. Claude Code did the building and fixed the setup problems that came up; I decided what the pages said and when something was ready to go live.

Claude Code capabilities used

  • Building and editing pages — creating the site, then making every later change as a small, targeted edit.
  • Previewing in a real browser — checking each change on desktop and phone sizes before it went live.
  • Generating design options — producing the five icon concepts for me to compare.
  • Publishing changes safely — recording every update so it could be reviewed and, if needed, undone.
  • Troubleshooting — working out what was going wrong during setup rather than guessing.

Outcome

  • A live portfolio built end to end with Claude Code, with no templates and no website builder.
  • Every change reviewed and approved before it went live, leaving a clear record of how the site evolved.
  • A site that has grown from two placeholder pages to five case studies, using the same simple process each time.
